State: action required

This state appears when the Watch app is installed but unreachable, or after a start command has not produced a sample. Do not call the Watch active merely because sendMessage was invoked.

Retry behavior

Check for Live HR re-evaluates reachability, sends a typed start request, shows Connecting, consumes a structured acknowledgement, and then waits for the first valid BPM. An acknowledgement proves command receipt; only a sample proves HR.

Escape routes

The user can switch to Bluetooth, retry Watch, cancel the start flow, or continue without HR. Cancel/switch/timeout sends a stop command when needed so a hidden Watch Health workout does not remain active.
