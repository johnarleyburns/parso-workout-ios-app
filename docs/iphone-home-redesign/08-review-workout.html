Review-mode default

Opening a past workout directly starts with all exercises collapsed. Opening via a Summary exercise row passes a focus ID, scrolls to that card after layout, and expands only it.

Exact actuals

Rows display stored weight, reps, and optional RPE; warm-ups remain labeled and partner sets remain attributed. Never derive the drill-in from summary aggregates because those omit warm-up and partner detail.

Edit semantics

Review mode keeps existing mutations: tapping a set edits the same SetEntry identity, Add Set appends once, Cancel mutates nothing, and deletions keep current confirmation behavior.

State isolation

Accordion state is transient view state keyed by exercise ID. Do not persist expansion in SwiftData or sync it through CloudKit.
