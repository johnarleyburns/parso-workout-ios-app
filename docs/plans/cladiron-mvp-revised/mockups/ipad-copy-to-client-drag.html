What a drag can do

Set row → itemReorder or move the set.
Exercise → sessionMove the exercise; loads preserved.
Exercise → roster rowCopy with %-recalculation to that client.
Exercise → another windowSame, across windows.
Session → dayReschedule.
Session → TemplatesSave as a template.
Template → roster rowInstantiate for that client.
On iPhone the same operation is the item's overflow menu → Copy to client…, with the recalculation preview shown before commit.
