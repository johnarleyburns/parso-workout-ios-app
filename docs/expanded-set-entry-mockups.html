Design direction

A lifting interface built for the last ugly rep.

One full-screen editor, every value in sight, and controls large enough for tired, chalky, sweaty hands. The Watch’s direct adjustment model comes to iPhone with more room, clearer context, and a fixed save action.

01

One screen, no maze

Weight, reps, effort, save, and cancel remain in one predictable vertical scan.

02

56 pt is the floor

Primary controls are 56–62 pt tall with generous separation and no tiny icon-only actions.

03

Watch-like adjustments

Pick an increment, then hit a huge minus or plus. The value is always visible and reversible.

04

Effort without friction

RPE/RIR is explicit, optional, and selected with a direct grid—no context menus or hidden sheets.

The same muscle memory for editing.

Add and edit share one layout. Existing values are loaded in place, the primary action becomes “Save changes,” and deletion stays secondary.

Page 03 · RIR mode

RPE and RIR are peers.

The mode switch is a primary control—not a hidden preference. The number grid stays in the same place, and the helper sentence explains the selected value in plain language.

A
Remember the lifter’s modeDefault future sets in this workout to the last-used RPE/RIR mode.
B
Store one canonical valueThe implementation may continue storing canonical RPE, while the editor converts cleanly at its boundary.
C
