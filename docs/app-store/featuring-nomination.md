# App Store featuring nomination — Cladiron

This is a submission-ready draft. The final submission still belongs in App
Store Connect; this document is not an Apple approval or a filed nomination.

## Core story

Cladiron is an interaction-first strength coach: a lifter logs a set in a few
seconds, sees the actual previous load and the reason behind today’s next
recommendation, then can continue phone-free on Apple Watch. The app is free,
open-source, private by design, and keeps the full JSON/FIT data path portable.

## Why now

This release connects the full loop: cited coaching, fast strength and cardio
logging, Apple Health import/export, FIT round trips, private backup, partner
workouts, Watch execution, Live Activities, and a transparent archive the user
can export at any time. No account, ads, telemetry, or developer-operated data
service is required.

## Suggested editorial copy

Cladiron makes the next set obvious without hiding the reasoning. It uses a
lifter’s real history, not rounded guesses, explains the recommendation, and
keeps the interaction compact enough for a gym floor. A partner can log their
own sets, a Watch can keep a session moving phone-free, and the user can take
the complete record with them through JSON or FIT export.
