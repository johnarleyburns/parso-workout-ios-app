Always discoverable

Show the performer row even when only Me exists. With no partners, the row’s Change action opens this sheet with Me plus Add Partner. Do not hide attribution behind the workout-level partner toolbar.

Add flow

Add Partner reuses case-insensitive findOrCreatePerson, scopes the person to session.activePartnerIDs, returns them to this picker, and selects them for the draft. Adding changes the session roster immediately; cancelling the set does not remove that newly added roster member.

Attribution integrity

Partner sets stay excluded from the owner’s PRs and Apple Health exactly as today. Editing attribution must run the existing repository update path so caches, history, and partner roll-ups refresh without duplicating the set.
