Ranking contract

Suggestions are deterministic and stable for a snapshot: safety/readiness first, then weekly modality deficits, muscle-volume gaps, plan/test actions, and progress observations. Existing engine priority is the first sort key; this UI must not invent a competing scoring system in SwiftUI.

One section, multiple sources

The list may merge Insight, the weekly Coach recommendation, passive readiness, and the fitness-test recommendation into one presentation model. De-duplicate equivalent claims before display.

Free Coach

Every action shown here works on the standard tier, including staged plan changes. There is no locked prescription, “Pro” chip, trial banner, upsell cadence, or entitlement branch.

Behavior

Expansion is local Home state and preserves scroll position. A history refresh re-ranks content but does not force-collapse an already expanded list during the same visit.
