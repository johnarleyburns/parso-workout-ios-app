Field fix 06 · iPhone + Watch intervals

Yellow is the final sixth, not a fixed 30 seconds.

Both renderers consume the same duration-aware signal. Tabata becomes 15 seconds green plus 5 seconds warning/imminent; boxing remains 150 seconds green plus 30 seconds warning/imminent.

Exact formula

For work duration D, warning duration is min(D, ceil((D / 6) / 5) × 5) seconds. State is green when remaining > warning duration, yellow when 3 < remaining ≤ warning duration, and imminent for the final 3 seconds. For 20: 5. For 45: 10. For 180: 30.

Single source of truth

IntervalSignal must receive both phase duration and remaining time. IntervalRunner exposes the effective duration. iPhone IntervalView and WatchIntervalView continue mapping the shared state to platform colors; neither owns threshold math.

Cues align

Pass the same warning threshold to IntervalCueDecider so the warning cue starts when yellow starts. Final-three-second ticks remain unchanged. Rest stays red; warm-up/cool-down stay neutral; color-blind mode retains its alternate work/rest palette.

Scope

This applies to every protocol with a timed work phase—HIIT presets, custom intervals, Tabata, boxing, and both phone/Watch runners. A steady-state cardio timer has no work/rest phase and therefore no green-to-yellow interval transition.
