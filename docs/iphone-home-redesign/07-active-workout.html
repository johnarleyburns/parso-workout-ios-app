Active-mode default

The current exercise is the only expanded card. The current set row is highlighted. Saving a set keeps that exercise open while it still has pending sets; completing its final planned set advances and expands the next unfinished exercise.

Manual control

Tapping any collapsed header expands it and collapses the previous card. Tapping the open header collapses it, allowing a zero-open state. The user’s manual choice persists until they log a set in another exercise or explicitly open another card.

Compact summary

Collapsed rows expose state, progress, and top load—not only the name. The whole header is a minimum 44 pt button with expanded/collapsed accessibility state.

Set editing

Tapping a completed or pending set still opens the existing full-screen set editor. Accordion behavior changes the exercise container, not set storage or entry semantics.
