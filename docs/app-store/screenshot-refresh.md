# Screenshot refresh gate

The checked-in screenshots are historical evidence, not the final award set.
Refresh them only after the device build containing the new Search tab, Quick
Talk hold flow, split layouts, PR takeover, and muscle-focus thumbnail has been
field-tested.

Required capture matrix: iPhone light/dark, iPad regular-width Progress,
Settings, and live session, and Watch strength/cardio. Every screenshot must
use seeded non-identifying data, contain no debug identifiers, and be reviewed
at the submitted pixel size. The preview storyboard is in
`preview-video-storyboard.md`.
