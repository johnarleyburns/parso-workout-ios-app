Nothing is keyboard-only. Every command here also appears in a toolbar, a context menu, or an item's overflow menu — iPad without a keyboard and iPhone are first-class.

Below iPadOS 26 the menu bar is unavailable; the same commands remain reachable through the toolbar and the palette, which is a presentation difference, not a capability difference.
