Per-set ownership

The draft owns performerID. Add defaults to roster rotation; edit preloads the recorded performer, including an attributed partner no longer active. Switching to Me saves nil. Cancel leaves the stored set unchanged.

Grid geometry

Four equal flexible columns, 8 pt gaps, and exactly equal 48 pt label/control frames. Apply the expanding frame to the Button label before styling. At accessibility sizes use two equal columns; never allow content width to determine cell size.

Responsiveness budget

The visible number/selection must update in the same frame cycle: ≤100 ms p95 from touch-up to committed UI on the oldest supported physical iPhone, with no event above 250 ms and no lost taps during a ten-tap burst.

Implementation direction

Freeze a stable editor context when the cover opens; do not rebuild it from SwiftData on every draft tap. Keep idle-activity tracking off the Session render invalidation path, prewarm/reuse haptics, and signpost tap receipt/state commit. Profile before/after to prove the stall is gone.
