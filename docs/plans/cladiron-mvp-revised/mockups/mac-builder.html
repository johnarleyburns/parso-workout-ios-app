What the Mac target owns — and what it doesn't

The shell, natively:
• Real menu bar from the shared .commands tree — every command in Appendix Y
• Multiple WindowGroup scenes with state restoration; ⌘N opens a client window
• NSSavePanel export, NSOpenPanel template import, printing, Services
• Right-click menus on set rows, items, sessions, roster rows, templates
• Native table behaviour, desktop row density, 28 pt pointer targets
Not the product:
• This grid, the prescription model, the engine surface, and the rationale components are literally the same CadenceUI views the iPhone and iPad render
No Mac-only capability, ever. A feature added to CadenceUI reaches all three idioms by construction, and CI fails the build if a CadenceUI view is compiled out under #if os(macOS). That rule is what keeps a second target from becoming a second product.
